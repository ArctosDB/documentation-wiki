Before deleting catalog records, first carefully consider the alternatives (such as Encumbrances and Redirects). In general, if there's any chance that a record has been cited, however informally, then the record should not be deleted.

Deleting is often appropriate for fixing mistakes in just-loaded records.

Redirecting URLs are recommended if there are replacement records for the ones to be deleted.

Please file an Issue if you have any doubt about deleting records.

## Tools

Arctos records may be deleted via the [Catalog Record Deletion bulk tool](https://arctos.database.museum/loaders/BulkDeleteCatalogRecord.cfm) found in the Tools Directory Record tile. The tool contains specific instructions. Various options in the search results tools menu contain GUID and can be used to send records to the deletion tool.

## Eligibility

Some records with certain dependencies may not be deleted.
