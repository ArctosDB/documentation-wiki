Some free-text fields accept Markdown; these generally have a 'markdown editor' button nearby.

## Benefits

Markdown provides a safe and simple alternative to HTML for formatting documents displayed as HTML.

## Drawbacks

Markdown-formtted text cannot undergo the 'clean checks' that other free-text fields in Arctos, and so is considerably less searchable.
