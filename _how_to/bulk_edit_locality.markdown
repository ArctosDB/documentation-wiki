# Edit Locality

This covers editing core Locality data;  Attributes and other related data are not considered.

## Names

``Locality_id`` is an ephemeral key and cannot be used as an identifier for asynchronous updates. Localities must be named to be bulk edited; a system for temporarily naming and un-naming localities exists.
